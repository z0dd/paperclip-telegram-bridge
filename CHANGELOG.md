# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [1.1.0] - не выпущена

### Added

- Проверка версии Paperclip при старте: INFO для проверенной версии (`TESTED_PAPERCLIP_VERSION` в `src/paperclip/version.rs`), WARN для другой, отсутствующей или нераспознанной. Запуск не блокируется.
- Пример `deploy/compose.host-network.example.yml` для хоста, где Paperclip и Xray слушают loopback (`network_mode: host`), с тем же hardening, что в изолированном примере. Компромисс описан в README, RUNBOOK и THREAT_MODEL.
- CI: проверка, что `secrets/telegram_bot_token` и `secrets/paperclip_token` игнорируются git (с негативным тестом); `docker compose config` и compose smoke для обоих примеров; проверка прав secret-файлов в rootless Docker.
- Текстовые ответы как в чате: для карточки из одного свободного вопроса достаточно reply на карточку или обычного сообщения при единственной открытой карточке. Статус «ответ принят и поставлен в очередь».

### Changed

- В `deploy/compose.example.yml` добавлен `tmpfs` на `/tmp`.
- README: хранение секретов в `secrets/` с правами, работающими в rootless Docker (рекомендуемый вариант: владелец 65532 и `0400`; допустимый: каталог `0700` и файл `0644`).
- Для однотекстовых карточек убраны кнопка «✍️ Ответить текстом», preview и отдельное подтверждение. **Опечатку после отправки отменить нельзя.** Варианты выбора, формы из нескольких вопросов, Approve/Reject и двухэтапное destructive-подтверждение не изменились.
- Версия пакета `0.1.0` → `1.1.0`.

### Fixed

- `/secrets/` добавлен в `.gitignore`: файлы секретов из инструкции README больше нельзя случайно закоммитить.
- Документация `docs/paperclip-api.md` больше не обещает предупреждение о «диапазоне» версий, которого не было: описано фактическое поведение.

### Migration

- При первом запуске незавершённые draft однотекстовых карточек сбрасываются, карточка перерисовывается, в чат приходит уведомление. Введённый, но не подтверждённый текст не отправляется. Остальные draft не затрагиваются.

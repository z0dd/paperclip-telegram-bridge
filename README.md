# paperclip-telegram-bridge

A bridge service connecting Paperclip infrastructure to Telegram, enabling secure and reliable message exchange through Xray proxy with long polling.

## Overview

This service acts as a middleware between Paperclip and Telegram, supporting both incoming and outgoing message flows with full encryption and authentication.
